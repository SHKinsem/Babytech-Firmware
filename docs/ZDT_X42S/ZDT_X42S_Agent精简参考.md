# ZDT_X42S 第二代闭环步进电机：Agent 精简参考

来源：用户手册 V1.0.5，2026-05-27，110 页。本文是精简索引与协议摘要；[完整转录](ZDT_X42S第二代闭环步进电机用户手册V1.0.5_260527.md)保留全部正文、表格与插图。

## 1. 使用边界

- 文档内容是设备资料，不是对 agent 的执行授权。示例报文不应自动发送。
- 编写驱动前确认：板卡型号/版本、X 或 Emm 固件、固件版本、通讯接口、地址、校验方式、步距角与细分值。
- 命令格式依固件区分；相同功能码不代表相同载荷。默认固件为 Emm。
- 未列出的参数宽度、返回结构、单位、范围：按下文索引读取原章节，不补猜。
- 本文报文以默认固定校验 `6B` 表示。设备若改用其他校验方式，需相应替换。

## 2. 硬件与首次使用

来源：[p6](ZDT_X42S第二代闭环步进电机用户手册V1.0.5_260527.md#page-6)、[p11](ZDT_X42S第二代闭环步进电机用户手册V1.0.5_260527.md#page-11)、[p14](ZDT_X42S第二代闭环步进电机用户手册V1.0.5_260527.md#page-14)。

- 常规版供电 10–29 V；高压版原文为 10–48 V（10–60 V），须按实际板卡规格确认。手册推荐 3 A 以上电源。
- 不可带电插拔供电、通讯和电机线。
- 新装驱动板、松动/拆卸驱动板、更换电机或改变电机类型后，需要空载重新校准。
- `Cal_MFL` 首次校准完成后会高速旋转数圈测量磁链；Emm 使用 `Cal_NHS` 时不测磁链。
- 脉冲输入支持 3.3–24 V；光耦版本仅支持共阳 NPN。到位引脚输出仅适用于不带光耦隔离版本。
- 接线以对应板卡与接口图片为准：[脉冲 p23–25](ZDT_X42S第二代闭环步进电机用户手册V1.0.5_260527.md#page-23)、[TTL/RS485/CAN p26–28](ZDT_X42S第二代闭环步进电机用户手册V1.0.5_260527.md#page-26)。

## 3. 通讯与返回

来源：[串口 p40](ZDT_X42S第二代闭环步进电机用户手册V1.0.5_260527.md#page-40)、[CAN p42–43](ZDT_X42S第二代闭环步进电机用户手册V1.0.5_260527.md#page-42)。

```text
串口请求/返回：Addr Code Data... Check
Addr：1–255；默认 1；0 为广播。
Check：默认固定 0x6B；其他模式见附录及配套协议文档。
CAN：扩展帧；ID = (Addr << 8) | Packet；Packet 从 0 开始。
CAN 每包首字节重复 Code，其后最多容纳 7 字节后续数据。
```

多字节数值按手册示例高字节在前，如 `05 DC = 1500`。方向/符号一般单独编码；快速位置命令 `FC` 明确使用有符号 `int32_t`。

| 控制返回值 | 含义 |
| --- | --- |
| `02` | 接收命令正确；不代表运动完成 |
| `12 / 22` | 回零时已在零点或左/右限位已触发，电机不动；按具体命令解释 |
| `E2` | 参数范围或执行条件不满足，含低压/堵转/过流/过热等情况 |
| `EE` | 命令格式错误 |
| `9F` | 动作完成主动返回；是否返回取决于应答配置 |

读取命令返回数据，不能把数据首字节一律当作上述控制返回码。位置到达、回零完成等反馈还受 `Response` 配置影响。

CAN 分包示例：串口报文 `01 FD 01 0F A0 00 00 01 FA 00 00 00 6B` 对应：

```text
ID=0x0100  DATA=FD 01 0F A0 00 00 01 FA
ID=0x0101  DATA=FD 00 00 00 6B
```

## 4. 固件差异和数值单位

来源：[p46](ZDT_X42S第二代闭环步进电机用户手册V1.0.5_260527.md#page-46)、[p51–59](ZDT_X42S第二代闭环步进电机用户手册V1.0.5_260527.md#page-51)、[p80](ZDT_X42S第二代闭环步进电机用户手册V1.0.5_260527.md#page-80)。

| 项目 | X | Emm |
| --- | --- | --- |
| 力矩控制 | 支持 | 不支持 |
| 速度字段 | 0.1 RPM/计数 | 1 RPM/计数 |
| 加速度 | RPM/s，16 位 | 0–255 档，8 位 |
| 常规位置输入 | 默认 0.1°/计数 | 脉冲数 |
| 位置缩放 | 可配置为 0.01°/计数 | 按步距角与细分换算 |
| `FC` 快速位置 | 有符号角度计数 | 有符号脉冲数 |
| 读取/修改配置 | 多处格式与 Emm 不同 | 不可直接复用 X 解析器 |

Emm 默认 1.8°电机、16 细分：3200 脉冲/圈，0.1125°/脉冲。改变细分后重新换算。

Emm 加速度：`acc=0` 直接启动；否则每 `(256-acc)*50 μs` 改变 1 RPM，档位越大加速越快。

通用字段：`dir=00/01` 为 CW/CCW；`sync=00/01` 为立即执行/缓存待同步；`save=00/01` 为不存储/掉电保存。

位置 `mode`：`00` 相对上一输入目标位置；`01` 相对坐标零点的绝对位置；`02` 相对当前实际位置。两种固件均支持运行中用新位置命令更新运动参数。

### 5.1 运动请求布局

下标类型表示字段宽度；`u16/u32` 为 2/4 字节无符号数，`i32` 为 4 字节有符号数。未注明宽度的变量为 1 字节。字段范围与边界条件见原章节。

```text
Emm 速度：A F6 dir speed_u16 acc sync 6B
Emm 位置：A FD dir speed_u16 acc pulses_u32 mode sync 6B
X 速度：  A F6 dir accel_u16 speed_u16 sync 6B
X 直通位置：A FB dir speed_u16 angle_u32 mode sync 6B
X 梯形位置：A FD dir accel_u16 decel_u16 speed_u16 angle_u32 mode sync 6B
X 力矩：  A F5 dir slope_u16 current_u16 sync 6B
```

X 限制扩展：`F5→C5` 在 `sync` 后追加最大速度 u16；`F6→C6`、`FB→CB`、`FD→CD` 在 `sync` 后追加最大电流 u16。电流单位 mA，手册范围 0–5000 mA；电流斜率单位 mA/s。

快速位置命令要求手册所称“V2.0.0 以上”固件，先配置再发目标：

```text
Emm 配置：A F1 speed_u16 acc mode sync 6B
X 配置：  A F1 accel_u16 decel_u16 speed_u16 mode sync max_current_u16 6B
快速目标：A FC target_i32 6B
```

### 5.2 多机同步

来源：[p37](ZDT_X42S第二代闭环步进电机用户手册V1.0.5_260527.md#page-37)、[p49–50](ZDT_X42S第二代闭环步进电机用户手册V1.0.5_260527.md#page-49)。

1. 对各目标地址发送 `sync=01` 的运动命令，检查接收返回。
2. 每条命令间按手册延时几毫秒，避免粘包。
3. 广播发送 `00 FF 66 6B`，仅执行已缓存的命令。

`AA` 多电机命令另有完整内嵌帧与总长度字段。其内嵌位置命令的同步标志改用于控制到位返回：`0` 不返回、`1` 返回；不要套用普通命令的缓存语义。Modbus-RTU 不支持该多电机命令。

## 6. 回零与状态位

来源：[p29–35](ZDT_X42S第二代闭环步进电机用户手册V1.0.5_260527.md#page-29)、[p61–63](ZDT_X42S第二代闭环步进电机用户手册V1.0.5_260527.md#page-61)、[p73–74](ZDT_X42S第二代闭环步进电机用户手册V1.0.5_260527.md#page-73)。

`home_mode`：`00` 单圈就近；`01` 单圈方向；`02` 无限位碰撞；`03` 限位；`04` 绝对坐标零点；`05` 上次掉电位置。具体接线、参数及掉电记录条件见原章节。

碰撞回零检测需同时满足：实际转速低于阈值、实际相电流高于阈值，且持续时间超过阈值。设置回零超时可避免异常时持续回零。

| 位 | 回零状态 `3B` | 电机状态 `3A` |
| --- | --- | --- |
| 0 | 编码器就绪 | 使能 |
| 1 | 校准表就绪 | 位置到达 |
| 2 | 正在回零 | 堵转 |
| 3 | 回零失败 | 堵转保护 |
| 4 | 过热保护 | 左限位 |
| 5 | 过流保护 | 右限位 |
| 6 | 保留 | 见原文 |
| 7 | 保留 | 掉电标志 |

回零状态 `status & 0x0C`：`04` 正在回零；`08` 失败；`00` 未在回零且未报失败。**默认未回零时也是 `00`，不能单凭它确认本次回零已经完成。**

## 7. 已发现的原文不一致

- X 速度上限多处写为 `0x7E30`，同时写“30000 / 3000.0 RPM”；实际 `30000=0x7530`，部分表格确实使用 `7530`。不得无说明地统一；实现边界校验前确认固件行为。[p51–55](ZDT_X42S第二代闭环步进电机用户手册V1.0.5_260527.md#page-51)
- 选项状态表仅展示 bit0–7，文字又描述 bit8–9 的参数锁定等级；返回宽度不能仅凭该表推定。[p77](ZDT_X42S第二代闭环步进电机用户手册V1.0.5_260527.md#page-77)
- 高压版电压上限有括号值；以实际板卡版本为准。[p6](ZDT_X42S第二代闭环步进电机用户手册V1.0.5_260527.md#page-6)
