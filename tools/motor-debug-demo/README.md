# Motor Debug Demo

电脑端电机调试交互原型，纯静态页面，没有真实 CAN 或硬件连接。

## 打开

直接双击 `index.html` 即可使用，无需安装依赖。

也可以在此目录运行 `python -m http.server 8765 --bind 127.0.0.1`，然后访问 http://127.0.0.1:8765 。

## 范围

- 单电机相对运动、参数编辑、运动反馈与停止。
- 双电机共用时间轴的梯形轨迹模拟。
- 日志是模拟命令事件，不是硬件 CAN 抓包。
- 不读写驱动器参数，不烧录、不使真实电机运动。

此目录是电脑端交互原型，尚未替换 brain 固件中的网页。确认交互后再接入实际的 brain → UART → motion → CAN 链路。
目标 CAN ID 可输入 1–255（0 为广播地址，不作为单机目标）。每个模拟 ID 独立保存位置与本页参数，切换 ID 不修改真实驱动器地址；两轴联动支持填写任意两个不同 ID。刷新页面会重置模拟状态。
