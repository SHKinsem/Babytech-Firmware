# Motor Debug Demo

描述对象：电脑端早期电机交互原型。Milestone：V1 历史原型，纯静态页面，没有真实 CAN 或硬件连接；不是当前固件或产品 SIM。当前 `V1-device`、Brain/Motion UART v4 入口见 [README](../../README.md)，实际 Motion 网页由另一个 [协议工作台](../motor-protocol-demo/README.md)生成。

## 打开

直接双击 `index.html` 即可使用，无需安装依赖。

也可以在此目录运行 `python -m http.server 8765 --bind 127.0.0.1`，然后访问 http://127.0.0.1:8765 。

## 范围

- 单电机相对运动、参数编辑、运动反馈与停止。
- 双电机共用时间轴的梯形轨迹模拟。
- 日志是模拟命令事件，不是硬件 CAN 抓包。
- 不读写驱动器参数，不烧录、不使真实电机运动。

本目录不作为待迁入 Brain 的工作项；当前 Brain 驱动屏幕并通过 UART v4 处理产品请求，旧 Brain 网页已退役。原型的模拟读数和轨迹不能当作当前控制器或真实运动证据。
目标 CAN ID 可输入 1–255（0 为广播地址，不作为单机目标）。每个模拟 ID 独立保存位置与本页参数，切换 ID 不修改真实驱动器地址；两轴联动支持填写任意两个不同 ID。刷新页面会重置模拟状态。
