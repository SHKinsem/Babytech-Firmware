# V1.0.5 网页更新验证（2026-09-22）

依据 `../../docs/ZDT_X42S/ZDT_X42S_Agent精简参考.md` 和同目录完整转录，对现有桌面工作台作协议内容更新。没有烧录、串口访问或真实电机操作。保留任务开始时已有的称重页、Wi-Fi 和板间协议改动。

## 更新

- 源码未定义但手册已确认的字段标为「手册明确」：CW/CCW、三种位置模式、六种回零模式、开/闭环、C5 的 0.1 RPM、X 位置角度及回零整数 RPM。
- 状态读取从 14 项增加到 21 项，新增 1A、26、32、34、39、3C、3D。板端增加相同只读白名单；控制模式限定 0/1，回零模式限定 0..5。原有运动监督范围不变。
- 对单包真实 RX 做严格长度、字节、符号、校验和地址检查，显示数值、状态位和手册解释。读取数据不当作 ACK；回零默认状态不当作本次回零完成。
- 查询结果按当前地址和功能码筛选，标注时间与历史属性；离线隐藏，板端重启清空历史。原始记录仍可查看。结果不参与运动授权或覆盖控制器反馈。
- 明确 X 固件协议、默认 0.1° 输入、固定 6B。没有自动固件类型识别，也没有新增 Emm 编码器。1A 宽度歧义、PID 和 42/43 多包回包保留原始数据。

## 执行与复核

Claude Code 运行模型为 `deepseek-flash[1m]`，服务 `api.deepseek.com`。同一会话 `bbe0597d-e2ad-44af-9270-4834f226fe66` 分两阶段完成协议模块与 UI 接入；两次运行无工具拒绝或网络重试。Codex 提取独立协议例子、修改板端白名单、执行测试并作小范围整合修正。

主要耗时在手册语义核对与审查，而不是样式修改。独立测试发现了非法符号字节被接受的问题；审查另外纠正了把输入缩放混用于反馈解释、声称手册未记载 42/43、将掉电标志扩大解释为记录有效等问题。按“协议检查点通过，再接 UI”的分工提前暴露了这些错误。网页编译成功不能替代协议语义审查。

任务 brief 为 `manual-v105-brief.md` / `manual-v105-ui-brief.md`。原始模型运行日志只保留在忽略目录 `.deepseek-runs/`。
