# 可调整调试限制

用户报告 F6 加速度 1000 RPM/s 被板端隐藏的 240 RPM/s 上限拦截，并要求自行调整。新增「调试限制」页面和 GET/POST `/api/limits`。六个值整体保存到 NVS 的 `debug-limits/config` 版本化记录，保存失败不改变 RAM 策略；开机校验完整记录后恢复。运行或使能/停止待确认时拒绝修改。

| 设置 | 首次默认 | 可配置范围 |
| --- | --- | --- |
| 速度上限 | 120 RPM | 0.1–3000 RPM |
| 加/减速度上限 | 240 RPM/s | 1–65535 RPM/s |
| 电流上限 | 5000 mA | 100–5000 mA |
| 单次相对行程 | 3600° | 0.1–360000° |
| 预估位置运动时长 | 60 s | 1–3600 s |
| 速度/力矩试验时长 | 5 s | 0–3600 s；0 为持续运行 |

速度 3000 RPM 采用手册十进制上限，手册同处十六进制存在矛盾。角度与时长上界是当前实现范围，不是宣称厂商限制。电流策略检查携带电流字段的命令；F6 不携带电流，需选 C6 才能同时指定限流。UART v2 参数协议自身的范围未在本次扩大。

表单/HEX/常规试动用同一已确认策略；输入保持原样，超限给出字段和当前范围。NVS 保存不会使能或发运动。关闭试验定时不关闭反馈超时、总线/运动故障与手动停止。取消日志覆盖操作结果，区分 HTTP 明确拒绝与网络结果未知。
